# 2026-07-26 接手 RAG 毕设项目并全线修复跑通

## 背景
收到工作交接文档：RAG 企业级知识库问答系统（FastAPI + React + LangChain），交接称卡在依赖安装。实际核实后发现交接文档多处过时，网络其实可用（pypi/npm/国内镜像全通）。

## 实际修复内容（全部完成并验证）
1. **依赖安装**：backend/.venv（Python 3.13）+ frontend/node_modules 均装好（阿里云/npmmirror 镜像）
2. **向量库降级**：chromadb 1.5.9 Rust 绑定 DLL 加载失败、0.6.3 需 MSVC 编译 → 改用 **FAISS**（faiss-cpu 1.14.3，纯 wheel），索引存 `backend/vector_db/kb_{id}/`
3. **Embedding 本地化**：实测 Agnes API 只有对话/图像/视频模型，**无 embedding 模型** → 自实现 `local_embeddings.py`（jieba 分词 + bigram + MD5 hashing trick，1024 维 L2 归一化）。注意：Python 内置 hash() 每次进程随机，必须用 MD5 保证跨进程确定性
4. **后端 bug**：auth.py 缺 `import settings`（登录 500）；`updated_at` 无 server_default 导致 ResponseValidationError（4 处模型 + SessionInfo schema 改 Optional）；pydantic-settings 新版不允许 .env 逗号分隔 List → ALLOWED_ORIGINS 改 str + property；main.py/init_db.py 建表前需先 import models
5. **流式问答**：`/send` 从 knowledge_base.py 移到 chat.py（`/api/chat/send`，与前端一致）；原文件 SSE 是字面量 `\\n\\n`（12 处，前端永远解析不出）；改为真流式（asyncio.to_thread 检索 + llm.astream 逐 token）；补齐消息持久化（user 消息先存，assistant 流完后另开 SessionLocal 存）；未绑知识库的会话自动检索用户可见全部知识库
6. **前端腐蚀修复**：api.ts 与 chatService.ts 共 5 处模板字符串 `${}` 丢失（无法编译）；package.json 补 @ant-design/icons；KnowledgeBase.tsx 补 BookOutlined import、删非法 `uploading` prop、删未用 import；Login.tsx 登录后调 getMe 存真实 role；ChatPage 加管理员知识库入口按钮 + 引用展示组件 ReferenceList；App.tsx 删未用变量
7. **init_db.py 重写**：通用 SQLAlchemy（不再依赖 psycopg），并自动导入示例商品数据建"电商商品知识库"（11 chunks 入 FAISS）
